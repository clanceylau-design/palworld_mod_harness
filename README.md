# Palworld Mod Harness

面向普通玩家的 AI Mod 创作平台探索项目。目标是让玩家通过若干轮自然语言对话表达创意，由预设 Agent 与游戏 Toolkit 生成、验证并交付可安装的 Palworld Mod。

当前产品方向聚焦：**由 AI 完成游戏内模型/纹理生成，并在保留原骨架和动画的前提下完成资产替换、打包与验证。**

## 当前阶段

项目处于产品和技术可行性验证阶段。首个建议 MVP 为 `AI Pal Skin`：选择一只 Pal，通过对话生成主题化纹理或受限外形变体，自动完成 Unreal Cook、游戏内预览以及 Mod 打包。
